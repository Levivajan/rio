# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability" (GitHub private vulnerability reporting).

Include the Rio version (About Rio), your macOS version, steps to reproduce and what an attacker gains. Reports that are also Chromium bugs should go to the Chromium project too (https://www.chromium.org/Home/chromium-security/reporting-security-bugs/); tell us if you did.

You will get an answer to your report as soon as the maintainer can read it. Please give us a reasonable time to ship a fix before you disclose.

## Supported versions

Only the latest release at https://github.com/Levivajan/rio-releases gets security fixes.
